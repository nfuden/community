# Agentgateway Community

Welcome! Agentgateway is excited you are interested in our community.

Agentgateway is an open source proxy built on AI-native protocols ([MCP](https://modelcontextprotocol.io/introduction) and [A2A](https://developers.googleblog.com/en/a2a-a-new-era-of-agent-interoperability/)) that provides drop-in security, observability, and governance for agent-to-LLM, agent-to-tool, and agent-to-agent communication across any framework and environment.

This repository contains helpful information regarding the structure and functioning of the agentgateway community, including how to get involved.
